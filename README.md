# 吃谷吧

一个简洁的二次元周边记账小程序，帮你记录吃谷（购买二次元周边）的每一笔支出。

## 功能

- 📝 快速记账：金额 + 分类 + 日期 + 图片
- 📂 分类管理：预设分类 + 自定义分类（手办、谷子、CD、周边等）
- 📊 统计报表：月度消费趋势、分类占比
- ☁️ 云端同步：数据自动备份到微信云开发，换手机不丢失

## 技术栈

- 微信小程序原生框架
- 微信云开发（云函数 + 云数据库）
- 无需后端

## 快速开始

1. 下载微信开发者工具
2. 导入项目，选择 AppID
3. 开通云开发控制台
4. 部署云函数目录下的 3 个云函数（addRecord、listRecords、deleteRecord）
5. 编译运行

## 项目结构

```
chigu/
├── app.js                  # 小程序入口
├── app.json
├── app.wxss
├── pages/
│   ├── index/              # 首页（快捷记账入口）
│   ├── add/                # 记账页面
│   ├── records/            # 记录列表
│   ├── detail/             # 记录详情
│   ├── stats/              # 统计报表
│   └── mine/               # 我的（分类管理、设置）
├── utils/
│   ├── storage.js          # 本地存储 + 云同步逻辑
│   └── format.js           # 格式化工具
└── cloudfunctions/
    ├── addRecord/          # 新增/更新记录
    ├── listRecords/        # 拉取记录列表
    └── deleteRecord/       # 删除记录
```

## 数据说明

- 数据以微信 OpenID 隔离，不同用户数据完全独立
- 本地优先存储，异步云端备份
- 换设备登录同一微信账号，数据自动合并
